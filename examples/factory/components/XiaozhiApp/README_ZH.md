# 小智应用

## 功能

在桌面的 AIChats 中进行语音对话，支持唤醒词、识别文字和回复字幕。连接兼容摄像头后，可拍照并进行视觉分析。

## 硬件需求

使用 ESP32-S3-Touch-LCD-3.5B 或 ESP32-S3-Touch-LCD-3.5B-C，连接扬声器并准备可访问互联网的 2.4 GHz Wi-Fi。摄像头功能需要 OV5640；首次使用需按界面提示完成服务激活。

## 怎么运行

完整编译烧录[出厂工程](../../README_ZH.md)，包括模型分区。在设置中配置 Wi-Fi，打开小智并完成激活，再使用 Talk 或唤醒词。

## 预期现象

应用显示识别文字和回复字幕，并播放语音回复。询问摄像头看到的内容可拍照并进行视觉分析；切换到音乐或麦克风测试前，先退出当前对话。

## 常见问题

无法对话时检查网络及激活状态。未连接摄像头或未配置视觉服务时，拍照工具返回错误。播放语音回复时暂停采音，仍可点击 Stop 停止。
