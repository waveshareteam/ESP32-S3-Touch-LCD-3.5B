# 小智应用

## 功能

将语音对话、激活、唤醒词检测和摄像头 MCP 工具接入产品桌面。Espressif 小智及 MCP 组件的本地适配版本与本应用一同保留；复用的小智资源在 [third_party/xiaozhi_esp32](third_party/xiaozhi_esp32/) 中保留许可证。

## 硬件需求

板载 ES8311 麦克风、扬声器、Wi-Fi 网络和已激活的小智账号。摄像头工具需要 OV5640。

## 怎么运行

完整编译烧录[出厂工程](../../README_ZH.md)，包括模型分区。在设置中配置 Wi-Fi，打开小智并完成激活，再使用 Talk 或唤醒词。

## 预期现象

应用显示识别文字和回复字幕，并播放语音回复。摄像头工具拍摄新图像，显示预览并提交给配置的视觉服务。音乐、麦克风测试和小智通过 BSP 共用音频资源。

## 常见问题

无法对话时检查网络及激活状态。未连接摄像头或未配置视觉服务时，拍照工具返回错误。播放语音回复时暂停采音，仍可点击 Stop 停止。
